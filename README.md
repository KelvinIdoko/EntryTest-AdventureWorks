# EntryTest AdventureWorks SQL Project

## Overview
This project was completed using the AdventureWorks2022 database in SQL Server Management Studio. It demonstrates core SQL skills including schema design, data insertion, joins, aggregation, and set operations.

## Features
- Schema creation (EntryTest)
- Table creation with constraints (PRIMARY KEY, FOREIGN KEY, CHECK, DEFAULT, UNIQUE)
- Data insertion from AdventureWorks tables
- UNION and UNION ALL queries
- INNER JOIN and LEFT JOIN operations
- GROUP BY with aggregation functions

## Tools Used
- SQL Server Management Studio
- AdventureWorks2022 Database
- Git & GitHub

## Notes
All queries were tested and executed successfully.
